## 附录：Qoder 浏览器连接器详解

### 什么是浏览器连接器

Qoder 的“电脑操控网页”能力，核心在于 **Browser Connector（浏览器连接器）**。它并不是远程控制你的整台电脑，而是 Qoder 桌面客户端通过一个本地代理或浏览器扩展，与你已经打开的 Chrome / Edge 浏览器建立连接。连接建立后，AI 就能像用户一样查看当前页面、点击元素、填写表单、截图，并返回操作结果。

### 连接是怎么实现的

1. **本地发现**：Qoder 启动后，会查找本机是否有受支持的浏览器实例（Chrome、Edge 等）以及对应的浏览器连接器。
2. **授权连接**：浏览器连接器需要用户授权，通常是点击一次“允许连接”或在 Qoder 设置里开启。
3. **页面通信**：授权后，Qoder 可以读取浏览器的标签页列表、当前 URL、页面结构（类似开发者工具里的 DOM 树）。
4. **指令下发**：当 AI 判断需要操作网页时，会通过连接器向浏览器发送指令，例如 `navigate`、`click`、`fill`、`evaluate_script`。
5. **结果回传**：浏览器执行完操作后，把新的页面状态、截图或脚本返回值传回给 AI，AI 再决定下一步。

整个过程中，AI **不会**直接访问你的操作系统文件，也 **不会**读取浏览器里保存的密码；它只能操作当前已连接浏览器中你已登录的页面。

### 典型应用场景

1. **手把手网页教学**：像创建 GitHub 仓库、配置后台系统这类“看十遍不如做一遍”的任务，AI 可以直接在浏览器里点给你看，同时口述每一步在做什么。
2. **批量重复操作**：例如批量审批飞书审批、批量导出报表、在电商后台批量上下架商品。只要把规则说清楚，AI 就能按列表逐条处理，减少机械劳动。
3. **跨系统数据搬运**：从 A 系统网页抓取数据，再自动填到 B 系统网页。例如把客户名单从 CRM 复制到营销平台，减少人工复制粘贴错误。
4. **自动化测试与验证**：让 AI 打开测试环境页面，执行登录、下单、支付流程，截图留存，帮助开发快速验证功能是否正常。
5. **信息检索与汇总**：让 AI 在多个网页之间跳转，搜索资料并整理成表格或文档，适合写调研报告、竞品分析。

### 对程序员工作的帮助

- **减少环境切换成本**：查文档、提 PR、看 CI 结果、部署上线，很多动作都在浏览器里，AI 可以帮你一站式完成。
- **快速复现 Bug**：用户反馈前端问题后，AI 可以打开页面、按步骤操作、截图，比文字描述更直观。
- **学习新工具和流程**：面对复杂的管理后台或新的 SaaS 工具，AI 可以直接演示，降低学习曲线。
- **自动化脚本替代品**：一些临时性、一次性的网页操作，不需要写 Selenium/Playwright 脚本，用自然语言描述即可。

### 对哪个职业帮助最大

如果单看“浏览器自动化 + 自然语言操控”这套能力，**测试工程师 / QA** 和 **运维 / SRE** 是受益最直接的：

- **测试工程师**：日常需要反复在浏览器里执行回归测试、验证 UI、截图留证。AI 连接器可以把“写测试脚本 → 运行 → 修复元素选择器”的周期，压缩成“说一句话 → AI 执行 → 人工确认结果”。
- **运维 / SRE**：需要登录各种云控制台、监控大盘、CI/CD 后台进行操作和巡检。浏览器连接器能帮他们快速完成查看日志、重启服务、审批发布等流程。

但这项能力对 **全栈开发者** 和 **产品经理** 也非常有价值：开发者能省下大量折腾网页管理后台的时间，产品经理则能更快完成竞品调研和后台配置。

### 使用边界与安全提示

- 只能控制已连接到 Qoder 的浏览器标签页。
- 涉及登录、支付、删除等敏感操作时，建议在已登录状态下由 AI 执行，并随时注意页面变化。
- 不要在未经验证的公共环境开启浏览器连接器，避免他人通过 Qoder 访问你的浏览器会话。
